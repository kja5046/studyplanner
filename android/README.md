# 스터디 플래너 안드로이드 앱

웹 플래너(https://kja5046.github.io/studyplanner/)를 앱 안에서 쓰고, 홈 화면에 **실시간으로 움직이는 "오늘 플래너" 위젯**을 띄우는 앱이에요.

## 위젯에서 되는 것

- 오늘 날짜, D-day, 오늘 공부시간, 완료 개수, 오늘의 한마디, '참 잘했어' 도장 표시
- 오늘 할 일 목록을 보고 **위젯에서 바로 체크**
- 앱에서 기록을 고치면 위젯이 바로 바뀌고, 자정이 지나면 다음 날 계획으로 바뀜
- 위젯 위쪽(날짜 부분)을 누르면 앱의 오늘 페이지가 열림

위젯에서 체크한 내용은 앱을 다음에 열 때 플래너에 함께 저장돼요.

## 빌드해서 폰에 설치하기 (처음 한 번)

1. PC에 **Android Studio**를 설치해요. (https://developer.android.com/studio)
2. Android Studio → **Open** → 이 `android` 폴더를 열어요.
   - 처음 열 때 필요한 파일을 자동으로 내려받아서 몇 분 걸려요.
   - "Gradle plugin을 업그레이드할까요?" 같은 창이 뜨면 그대로 진행해도 돼요.
3. 폰에서 **개발자 옵션 → USB 디버깅**을 켜고 USB로 PC에 연결해요.
   - 개발자 옵션: 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호를 7번 누르기
4. Android Studio 위쪽에서 내 폰을 고르고 ▶ (Run)을 누르면 앱이 설치돼요.
5. 폰 홈 화면을 길게 누르기 → **위젯** → **스터디 플래너 / 오늘 플래너**를 끌어다 놓아요.

APK 파일로 만들어 다른 폰에 옮기려면: 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)** → 완료 알림의 `locate`를 누르면 `app-debug.apk`가 있어요. 이 파일을 폰에 옮겨 설치하면 돼요(출처를 알 수 없는 앱 설치 허용 필요).

## 기기끼리 동기화 (구글 드라이브)

앱을 설치한 폰·태블릿끼리 구글 드라이브의 파일 하나로 기록을 맞춰요. 서버나 로그인은 필요 없어요.

1. 모든 기기에 **Google Drive 앱**이 설치되어 있고, **같은 구글 계정**으로 로그인되어 있어야 해요.
2. **처음 기기:** 앱 → 설정 → 구글 드라이브 데이터 동기화 → `처음 기기: 동기화 파일 만들기` → 파일 선택 창 왼쪽 메뉴에서 **Google Drive** → 저장
3. **다른 기기:** 앱 → 설정 → `다른 기기: 기존 파일 연결` → Google Drive에서 `planner-sync.json` 선택
4. 이후에는 자동이에요. 앱을 열 때 드라이브의 최신 기록을 가져오고, 고친 뒤 몇 초 지나거나 앱을 나갈 때 드라이브에 올려요.

- 같은 날짜를 두 기기에서 동시에 고치면 **나중에 고친 쪽**이 남아요. 서로 다른 날짜·페이지를 고친 건 둘 다 남아요.
- 필기와 스티커도 함께 동기화돼요.
- 드라이브가 파일을 올리고 받는 데 몇 초~몇십 초 걸릴 수 있어요. 바로 안 보이면 설정의 `지금 동기화`를 누르세요.
- 이 기능은 안드로이드 앱에서만 보여요. 아이패드·PC 브라우저는 백업 파일로 옮기세요.

## 기록 옮기기

앱은 Chrome과 저장 공간이 따로라, 처음에는 기록이 비어 있어요.

1. 원래 쓰던 기기(Chrome, 아이패드 등)의 플래너에서 **설정 → 백업 파일 내려받기**
2. 그 파일을 폰으로 옮기고, 앱에서 **설정 → 백업 불러오기**로 선택

앱에서 백업을 내려받으면 폰의 **다운로드** 폴더에, 위젯 화면의 '이미지로 저장'은 **사진(Pictures/StudyPlanner)**에 저장돼요.

## 알아두기

- 앱은 GitHub Pages의 플래너를 불러와요. 웹을 고쳐서 push하면 앱도 다시 빌드할 필요 없이 바로 바뀌어요.
- 플래너 주소가 바뀌면 `app/src/main/java/com/kja5046/studyplanner/MainActivity.java`의 `PLANNER_URL`만 고치고 다시 빌드하세요.
- 안드로이드 10 이상에서 동작해요.
