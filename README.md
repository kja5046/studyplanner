# 스터디 플래너 (웹 속지)

아이패드·PC 브라우저에서 쓰는 공부 플래너입니다. 서버 없이 정적 파일만으로 돌아가서 GitHub Pages에 그대로 올려 쓸 수 있어요.

## 페이지 구성

| 탭 | 내용 |
|---|---|
| 일간 | 과목별 할 일 18칸 + 완료 체크, 05~04시 10분 단위 타임라인(과목 색으로 칠하면 공부시간 자동 합산), D-day, 오늘의 한마디, 피드백 |
| 월간 | 달력(날짜별 메모, 하루 공부시간 자동 표시), 이달의 목표, 날짜를 누르면 그날 일간으로 이동, 이달의 평가 바로가기 |
| 이달의 평가 | 칭찬해/아쉬워, 월 총 공부시간과 과목별 막대, 과목별 내용 + 별점 10줄, 콘텐츠·음악·좋았던 것·책·음식·장소 |
| 과목별 계획 | 과목 카드 4개(목표, 체크리스트 9줄, 메모), 페이지 추가 가능 |
| 인강 | 강좌 4개(과목·선생님·강좌·기간·메모 + 1~60강 체크), 페이지 추가 가능 |
| 시험 결과 | 시험 10회분 과목별 점수·등급 표, 점수 추이 그래프, 칭찬해/아쉬워 |
| 설정 | D-day, 과목 이름·색·순서, 백업 내려받기/불러오기, 초기화 |

모든 페이지 위에 **필기 레이어**가 있어요. 오른쪽 사이드 탭의 연필 버튼을 누르면 펜·형광펜·지우개·굵기·실행취소가 펼쳐지고, 손 모양 버튼을 켜면 애플펜슬로만 써지고 손가락으로는 스크롤돼요.

하루 기록 왼쪽 위 스티커 칸을 누르면 그날만의 사진이나 그림을 붙일 수 있고(설정의 기본 스티커는 붙이지 않은 날에 연하게 보여요), 아래 `참잘했어` 리본을 누르면 그날 칭찬 도장이 찍혀요.

## 계획 붙여넣기

하루 기록 위쪽 `붙여넣기` 버튼을 누르고 아래 형식의 글을 붙여 넣으면 칸이 자동으로 채워져요. `PLANNER_PROMPT.md`를 AI에게 주고 "내일 계획 짜줘"라고 하면 바로 붙일 수 있는 글을 받을 수 있어요.

```
날짜: 2026-10-17
한마디: 더딘 것을 염려하지 말고 멈출 것을 염려하라
출처: 공자
아침 | 영어 단어 30개
     | 듣기 2회
국어 | 문학 기출 3회분
- 구분 없이 쓰는 할 일
[x] 이미 끝낸 일
메모: 저녁엔 오답 정리
```

- `|` 왼쪽은 구분(시간대·과목), 오른쪽은 할 일이에요.
- `날짜:` 줄이 있으면 그 날짜에 넣을지 물어봐요. 없으면 보고 있는 날짜에 들어가요.
- `빈 칸에 넣기`는 이미 쓴 내용을 두고 빈 줄부터 채우고, `바꾸기`는 그날 할 일·한마디·메모를 새 내용으로 바꿔요. 타임라인과 필기는 그대로예요.

## 위젯 (오늘 한눈에 보기)

`https://kja5046.github.io/studyplanner/widget.html` 을 열면 오늘 날짜의 플래너가 작은 카드로 보여요. D-day, 오늘 공부시간, 할 일과 체크, 공부 시간표, 칭찬 도장이 들어가고, 할 일 체크는 위젯에서 바로 할 수 있어요. 같은 브라우저의 플래너 창에서 고친 내용은 위젯에 바로 반영되고, 자정이 지나면 다음 날로 바뀌어요.

- **Windows:** Chrome이나 Edge에서 위젯 주소를 열고 주소창 오른쪽 설치 아이콘(또는 메뉴 → 앱 설치)을 누르면 작은 창의 앱으로 설치돼요. 창 크기를 줄여 화면 한쪽에 두고, 항상 위에 띄우려면 PowerToys의 "항상 위" 기능(Win + Ctrl + T)을 쓰세요.
- **아이패드:** 사파리에서 위젯 주소를 열고 공유 → 홈 화면에 추가를 하면 "오늘" 아이콘이 따로 생겨요. Slide Over나 스테이지 매니저의 작은 창으로 띄워 두면 위젯처럼 쓸 수 있어요.
- **사진 위젯으로:** 위젯 아래 `이미지로 저장`을 누르면 오늘 플래너가 사진으로 저장돼요. 아이패드 홈 화면의 사진 위젯이나 PC 바탕화면에 넣으면 캡처처럼 보여요. 사진은 저장한 시점 그대로라, 바뀐 내용은 다시 저장해야 해요.

위젯은 같은 기기·같은 브라우저에 저장된 기록을 보여줘요. 아이패드 위젯은 아이패드 사파리의 기록, PC 위젯은 PC 브라우저의 기록이에요.

## 데이터 저장

- 글자·체크·타임라인은 브라우저 `localStorage`, 필기는 `IndexedDB`에 저장돼요.
- **기록은 그 기기, 그 브라우저에만 남아요.** 다른 기기와 자동으로 동기화되지 않아요.
- 설정 → `백업 파일 내려받기`로 전체(필기 포함)를 `.json` 파일로 저장하고, 다른 기기에서 `백업 불러오기`로 옮길 수 있어요.
- 아이패드 사파리는 홈 화면에 추가하지 않은 사이트의 저장 데이터를 오래 안 쓰면 지울 수 있어요. **홈 화면에 추가해서 쓰고, 주기적으로 백업**하는 걸 권해요.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만들어요 (예: `study-planner`, Public).
2. 이 폴더 안의 파일을 전부 저장소 최상위에 올려요.
   - 웹에서: 저장소 → `Add file` → `Upload files` → 파일과 `icons` 폴더를 끌어다 놓고 `Commit changes`
   - 터미널에서:
     ```bash
     cd study-planner
     git init && git add . && git commit -m "first commit"
     git branch -M main
     git remote add origin https://github.com/<아이디>/study-planner.git
     git push -u origin main
     ```
3. 저장소 → `Settings` → `Pages` → Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 하고 `Save`.
4. 1~2분 뒤 `https://<아이디>.github.io/study-planner/` 로 접속해요.
5. 아이패드 사파리에서 열고 `공유` → `홈 화면에 추가`를 누르면 앱처럼 전체 화면으로 열리고 오프라인에서도 열려요.

> 저장소가 Public이어도 **기록 내용은 각자의 브라우저에만 저장**되기 때문에 다른 사람이 볼 수 없어요. 공개되는 건 빈 플래너 코드뿐이에요.

## 내 컴퓨터에서 미리 보기

```bash
cd study-planner
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`index.html`을 더블클릭해서 열어도 대부분 동작하지만, 오프라인 기능(서비스워커)은 `http://localhost`나 `https`에서만 켜져요.

## 수정하기

- `style.css` 맨 위 `:root` 색 변수로 전체 색감을 바꿀 수 있어요.
- 기본 과목은 `app.js`의 `DEFAULT_SUBJECTS`, 일간 할 일 줄 수는 `TASK_ROWS`, 타임라인 시작 시각은 `START_HOUR`예요.
- 파일을 고친 뒤 GitHub에 다시 올리면 반영돼요. 홈 화면 앱에서는 한 번 껐다 켜면 새 버전으로 바뀌어요. 바로 바뀌지 않으면 `sw.js`의 `CACHE` 이름(지금은 `study-planner-v6`)과 `index.html`·`widget.html`의 `?v=6`을 `v7`처럼 함께 올려 주세요.
